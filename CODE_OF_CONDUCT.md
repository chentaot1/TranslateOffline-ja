# Code of Conduct

TranslateOffline-ja's issues, pull requests, and discussions are dedicated to building and using the application. Everyone participating is expected to:

- Be respectful and patient, especially with newcomers and contributors writing in a second language.
- Critique code, architecture, and ideas, not individuals.
- Keep discussion constructive and on-topic.

Not accepted: harassment, discriminatory language, insults, personal attacks, or publishing private information.

Sharing or requesting pirated manga scans is strictly off-limits. Please use self-owned, open-domain, or freely licensed comic pages when posting reproduction examples or bug reports.

## Enforcement

Report issues via GitHub's **Report content** option on the respective comment, issue, or pull request. Repository maintainers moderate discussions to keep the community welcoming and focused.
