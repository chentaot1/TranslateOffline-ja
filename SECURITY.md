# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/chentaot1/TranslateOffline-ja/security/advisories/new), rather than opening a public issue.

## Supported Versions

Only the latest release is supported. TranslateOffline-ja runs entirely on-device and has no server backend. Reports regarding local intent guards, MediaProjection lifecycle, memory security, or the bundled `llama.cpp` runtime are in scope.
